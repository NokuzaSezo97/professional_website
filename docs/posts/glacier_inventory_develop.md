# New GitHub Repository: Glacier Inventory Development

A new github repository has been created to share my recent experiences with the glacier inventory development using free and open-source softwares such as Google Earth Engine, QGIS and python language.

This repository supports information to any researchers/students who want to start off with glacier mapping/glacier inventory development but with limited capacity.

Please check out the repository from this [link](https://github.com/NokuzaSezo97/establishing_glacier_inventory) from where you can access sample GEE scripts, supplementary information and sample datasets.
